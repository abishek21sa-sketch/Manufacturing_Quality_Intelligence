# Validation Protocol

A work package is not marked validated merely because code exists.

The repository validation command must:
1. Generate reproducible data.
2. Validate its contract.
3. Train/evaluate the defect model using a temporal holdout.
4. Compute SPC and capability outputs.
5. Execute a balanced MSA study.
6. Run Monte Carlo quality-impact simulation.
7. Solve an inspection decision under a capacity constraint.
8. Persist machine-readable evidence.
9. Pass automated tests.

`artifacts/validation_report.json` records the analytical evidence generated by the current code revision.
